# Documentation Index

This directory contains user-facing guides for `rustfs-kafka` and
`rustfs-kafka-async`.

## Guides

- `usage-guide.md`: End-to-end usage for sync and async crates.
- `api-guide.md`: API-oriented examples and patterns.

## Architecture & Analysis

- `protocol-coverage.md`: Kafka protocol API coverage matrix (87 APIs).
- `code-splitting-analysis.md`: File splitting analysis for large-file refactoring.
- `analysis/`: Deep-dive analysis documents (TLS audit, cert chain, etc.)
